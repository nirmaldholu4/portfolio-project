## 📖 About the Project

This portfolio website is designed to showcase a developer's skills, services, projects, and contact details in a clean, professional, single-page layout. It uses a dark navy background with orange highlights to create a modern, tech-focused aesthetic. The entire UI is built using reusable React components, making it easy to customize, extend, or convert into a multi-page site.

Whether you're a developer looking for a portfolio template or want to learn how a real-world React + Bootstrap project is structured, this repo is a great starting point.

---

## ✨ Key Features

- 🎨 **Modern Dark UI** – Elegant dark-blue theme with orange accent colors throughout
- 📱 **Fully Responsive** – Optimized layouts for mobile, tablet, and desktop screens
- 🧭 **Sticky Navigation Bar** – Smooth scrolling navbar with a collapsible mobile menu
- 🏠 **Hero / Home Section** – Eye-catching introduction with profile image and stats (Projects, Years, Clients)
- 🛠️ **Services Section** – 6 animated service cards with icons (Web Dev, Mobile Dev, UI/UX Design, etc.)
- 👤 **About Me Section** – Two-column layout with image, bio, and personal info grid
- 💪 **Skills Section** – Visual skill cards with animated progress bars
- 💼 **Projects Section** – Showcase cards with images, tech badges, and Live Demo / GitHub buttons
- ✉️ **Contact Section** – Contact info card + a styled contact form UI
- 🔗 **Social Links** – GitHub and LinkedIn integration
- ⚡ **Fast & Lightweight** – Powered by Vite for instant hot-reload during development
- 🎯 **Hover Effects** – Smooth card lift and border-glow animations on hover

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/your-repo.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd your-repo
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

5. **Open in browser**
   Visit `http://localhost:5173` to view the app.

6. **Build for production** (optional)
   ```bash
   npm run build
   ```

## 🧩 Sections Overview

### 🧭 Header
Sticky, dark navbar with the logo, navigation links (Services, About, Skills, Projects, Testimonials, Contact), and a prominent "Let's Talk" call-to-action button. Includes a responsive hamburger menu for mobile.

### 🏠 Home
The hero/landing section featuring a headline introduction, short tagline, two CTA buttons (Contact Me / Download CV), quick stats (Projects, Years, Clients), and a framed profile image.

### 🛠️ Services
A 3-column responsive grid of 6 service cards, each with an icon, title, and short description — covering Web Development, Technical Writing, Mobile Development, Email Marketing, UI/UX Design, and Web Design.

### 👤 About
A two-column section combining a framed illustration/image with a personal bio and a quick-info grid (Name, Experience, Location, Email).

### 💪 Skills
A grid of skill cards, each showing a technology icon, name, proficiency percentage, and an animated progress bar (HTML/CSS, JavaScript, React, Node.js, Python, UI/UX Design).

### 💼 Projects
Three project cards with cover images, titles, descriptions, technology badges, and Live Demo / GitHub action buttons.

### ✉️ Contact
A two-column layout with a "Get In Touch" info card (email, phone, location, social icons) alongside a styled contact form (Name, Email, Subject, Message).

### 🔻 Footer
A minimal footer with copyright text and the developer's name highlighted in orange.
