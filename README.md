# ✨ 🚀 My Portfolio

A modern, fully responsive personal portfolio website built with **React**, **Vite**, and **Bootstrap 5**.

The portfolio features a sleek dark theme with vibrant orange accents, smooth hover effects, responsive layouts, and a clean developer-focused design.

## 📖 About the Project

This portfolio website is designed to showcase a developer's skills, services, projects, and contact details in a clean and professional single-page layout.

The website uses a **dark navy background** with **orange highlights** to create a modern and technology-focused appearance.

The project is built with React and Bootstrap, making the layout responsive and easy to customize.

---

## ✨ Key Features

- 🎨 **Modern Dark UI** – Dark navy theme with orange accent colors
- 📱 **Fully Responsive** – Works on mobile, tablet, and desktop
- 🧭 **Sticky Navigation Bar** – Easy navigation between sections
- 🏠 **Hero / Home Section** – Introduction with profile image and statistics
- 🛠️ **Services Section** – Six service cards with icons and descriptions
- 👤 **About Me Section** – Developer information and personal details
- 💪 **Skills Section** – Skills with percentage and progress bars
- 💼 **Projects Section** – Project cards with images and technology badges
- ✉️ **Contact Section** – Contact information and contact form
- 🔗 **Social Links** – GitHub and LinkedIn links
- ⚡ **Fast Development** – Powered by Vite
- 🎯 **Hover Effects** – Smooth hover animations and card effects
